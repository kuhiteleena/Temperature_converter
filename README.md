# Temperature Converter 🌡️

A simple and responsive **Temperature Converter** web application built using **HTML, CSS, and JavaScript**.  
It allows users to easily convert temperatures between **Celsius**, **Fahrenheit**, and **Kelvin**.

## 🚀 Live Demo

👉 https://temperatureconvertorlk.netlify.app

## ✨ Features

- Convert temperature between:
  - Celsius (°C)
  - Fahrenheit (°F)
  - Kelvin (K)
- Instant conversion results
- Clean and user-friendly interface
- Responsive design for all devices
- Beginner-friendly project structure

## 🛠️ Technologies Used

- **HTML** – Structure
- **CSS** – Styling and layout
- **JavaScript** – Conversion logic

## 📁 Project Structure

```temperature_converter/
├── index.html # Main HTML file
├── style.css # Styling
├── app.js # JavaScript logic
└── README.md # Project documentation
```

## 📌 How to Run the Project

1. Clone the repository:
   git clone https://github.com/kuhiteleena/temperature_converter.git  
2. Navigate to the project folder: cd temperature_converter
3. Open index.html in your browser.
